# 历史版本归档

`吞食天地三国` 项目确认版本的旧源码归档在这个目录。当前主推进源码位于
`网页复刻/吞食天地Ⅱ同人复刻-网页版/`；根目录的 `three-kingdoms.html`
仍是早期 FC 风单文件版，仅作历史保留。

## 命名规则

- 早期源文件：`three-kingdoms.html`
- 早期归档文件：`three-kingdoms-vX.Y.Z.html`（版本号与 `更新记录.md` 中的条目一致）
- 网页复刻版本归档：按版本在本目录下建立对应目录，保留入口与运行时源码快照。

## 归档时机

- 只有经过用户确认的版本才算新版本。
- 确认新版本时：把即将被替换的上一版 `three-kingdoms.html` 复制归档到这里，再在 `更新记录.md` 末尾追加记录。
