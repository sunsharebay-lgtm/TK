# 吞食天地三国

基于原版数据复刻的三国 RPG 网页复刻项目。

- 主推进：`网页复刻/吞食天地Ⅱ同人复刻-网页版/`（完整 MZ 兼容引擎、553 张地图、60+ 武将）。
- 历史保留：`three-kingdoms.html`（早期 FC 风单文件版）。
- 入口：`index.html` 跳转到当前网页复刻版。
- 素材：`素材/`；文档：`文档/`；测试：`测试/`。
- 版本：Git 标签 `game/three-kingdoms/vX.Y.Z`。

## 工作边界

- 所有三国源码、数据、素材、文档、测试与历史版本只放本文件夹。
- 重要阶段完成后先在 `更新记录.md` 末尾记录，并把旧源码归档到 `历史版本/`；确认发布再打版本标签。
