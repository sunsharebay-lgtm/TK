# 吞食天地三国

基于原版数据复刻的三国 RPG 网页复刻项目。

- 主推进：`网页复刻/吞食天地Ⅱ同人复刻-网页版/`（完整 MZ 兼容引擎、553 张地图、60+ 武将）。
- 历史保留：`three-kingdoms.html`（早期 FC 风单文件版）。
- 入口：`index.html` 跳转到当前网页复刻版。
- 素材：`素材/`；文档：`文档/`；测试：`测试/`。
- 版本：Git 标签 `game/three-kingdoms/vX.Y.Z`。

## 当前玩法约定

- 敌方策略先消耗谋略点，策略概率和效果受武将智力影响；敌方无被动回复，普通回复为固定基础值加智力倍率，完复计直接补满。
- 大地图带 `<TroopVariables: 21>` 的空遭遇表使用按队伍等级分层的敌群，约 40 步触发一次遇敌。
- 菜单切换武将使用 `U/I`；战斗经验按敌群原始经验的 `1.25` 倍结算。
- 宝箱领取后显示打开状态；第一章纪灵战后按提示挑战袁术，寿春山洞入口在剧情阶段达到后开放。
- 普通战斗和总攻均包含敌方还击；行动动画放慢，伤害浮字显示在受击者附近。
- 装备库存支持重复武器/防具，武将武力采用历史基准并叠加装备，物理攻击随当前兵力规模提升；策略消耗约为原始值的三分之二。
- 物品页显示道具、武器和防具，确认物品后可使用或丢弃 1 个；武器店、道具店和防具店均支持出售，出售价格为买入价的 75%，商店中按 `Q` 出售、`E` 购买。
- 存档页的光标与记录行严格对应，选择记录一会写入槽位一，不会偏移到记录二。
- 袁术最终战斗胜利后第一章标记完成，沿山洞出口回到大地图、再向西南返回徐州收尾；阶段 `80→1655` 的后续主线地图、事件和二周目秦皇陵数据已接入运行时，按章节规划继续推进。
- 全章节阶段索引已注册：河北与千里走单骑、荆州新野、赤壁平荆州、西蜀、汉中姜维、灭曹魏、伐吴终局和二周目秦皇陵。
- 郑家村已补充村民和郑玄居路线提示；推进到相应剧情后，进入郑玄居可取得推荐袁绍的书信。
- 郑家村村民位于湖西侧陆地，不会站在湖中；新加入武将按当前队伍平均等级加入并恢复满兵力。
- 招魂丹可在物品页选择阵亡武将使用，阵亡武将会出现在复活目标列表中。
- 非战斗单体恢复计策会先进入目标选择，选择陈登等指定武将后才扣谋点并恢复对应兵力；没有阵亡目标时复活计策会明确提示。
- 郑玄居事件兼容网页版跳过登录流程，郑玄在拥有地图时可正常取得书信并推进剧情；原始物品条件按 MV 的 `[类型, id]` 格式判断。
- 客栈使用 `\G` 只显示货币单位，第一章住宿价格为 4 金；训练场会根据队伍当前等级判断是否可训练。
