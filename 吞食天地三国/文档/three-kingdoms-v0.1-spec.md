# 吞食天地：汉末群雄 v0.1 设计规格

## 目标

在现有 TK 小游戏中心中加入第二款游戏“吞食天地：汉末群雄”，制作一款原创 FC 风格三国 RPG 第一版。第一版以可玩的垂直切片为目标，验证探索、队伍管理和回合制战斗的核心手感，不复制任何既有游戏的具体画面、地图、音乐、文字脚本、数值表或关卡数据。

## 产品定位

游戏面向喜欢 FC 时代三国 RPG 的玩家，使用低分辨率感、限制色盘、俯视角像素地图和简洁菜单制造时代气质。游戏的正式名称使用“吞食天地：汉末群雄”，与参考作品区分；核心世界观采用原创章节、原创地图和原创数值。

第一版从小游戏中心进入，独立页面使用 `three-kingdoms.html`。页面不依赖服务器，能够直接在 GitHub Pages 上运行。

## 版本策略

版本号按游戏分别管理，不再让第二款游戏共用坦克大战的全局版本号。

坦克大战的新标签格式为：

```text
game/tank-battle/v1.6.1
```

本游戏的第一版标签格式为：

```text
game/three-kingdoms/v0.1.0
```

现有的 `v1.6.1` 标签继续保留兼容。游戏目录生成器读取每个游戏自己的最新 `game/<id>/vX.Y.Z` 标签，生成每个卡片的版本号和稳定版状态。普通提交、文档提交和测试提交不改变游戏版本。

## 第一版玩法范围

第一版包含一个标题画面、一个可探索的野外区域、一个城镇、一个军营、一个山道和一个首领战区域。地图布局全部原创，不复刻参考作品的地形排列、城池位置或路线。

玩家拥有三名初始武将。队伍可以在地图上移动，进入地点，和 NPC 对话，打开宝箱，恢复兵力，并触发战斗。第一版包含一次原创武将加入事件，玩家完成事件后可以从四名武将中选择三名组成出战队伍。

战斗采用回合制指令菜单。每名武将每回合可以选择攻击、计策、防御、道具或撤退。战斗以“兵力”和“士气”作为主要状态，敌方使用三种原创兵种。玩家可以使用三种原创计策：火势压制、鼓舞士气和疑兵扰乱。首领战要求玩家至少使用一次计策才能稳定取胜，但不要求复刻任何既有作品的战斗流程或数值。

战斗结束后，队伍获得经验和军粮。军粮用于恢复队伍兵力，经验用于提升武将等级。第一版提供一次升级和一次营地恢复，避免先实现完整长篇 RPG 的所有成长系统。

## 操作

键盘操作使用方向键或 WASD 移动，Enter 或 Z 确认，Esc 或 X 返回，数字键 1 至 5 选择战斗指令。移动端提供方向键、确认和返回按钮。所有按钮支持键盘焦点，触屏区域不会遮挡主要地图和战斗菜单。

## 视觉和声音

游戏使用 256×240 的虚拟画布，再按整数比例放大到浏览器窗口。地图使用 16×16 的原创代码生成像素图块，控制在 16 色以内。角色、敌人、建筑、菜单图标和特效全部由项目内代码绘制或使用明确允许修改和再分发的素材。

第一版默认不引入网上来源不明的截图、ROM 提取资源、原作立绘、原作地图、原作音乐或原作音效。若以后使用 CC0、允许改编的 CC BY 或已取得授权的素材，必须在项目内记录来源、作者、许可证和修改方式。音乐和音效优先使用 WebAudio 程序化生成，保证 GitHub Pages 可直接加载。

## 技术架构

游戏使用独立的 `three-kingdoms.html`，包含画布、样式、输入层、地图数据、战斗状态机和程序化音频。第一版不修改坦克大战的游戏代码，不共享全局变量，不加载第三方运行时依赖。

游戏状态机至少包含 `title`、`world`、`dialogue`、`battle`、`battle-result`、`camp` 和 `game-over`。地图、武将、敌人、计策和物品使用数据表定义，渲染器只负责显示状态，输入层只负责产生动作，战斗系统只负责计算结果。

小游戏中心的 `game-catalog.json` 增加本游戏记录：

```json
{
  "id": "three-kingdoms",
  "title": "吞食天地：汉末群雄",
  "url": "./吞食天地三国/three-kingdoms.html",
  "version": "v0.1.0",
  "status": "稳定版"
}
```

GitHub Pages 工作流和版本目录生成器同步升级，分别读取坦克大战与本游戏的命名空间标签。

## 存档与兼容

第一版使用浏览器本地存档，保存当前区域、队伍、等级、兵力、军粮、已触发事件和已获得物品。存档键使用带版本前缀的名称，例如 `tk-three-kingdoms-v0`，不会读取或覆盖坦克大战存档。

如果存档数据损坏，游戏显示“存档无法读取，请开始新游戏”，并提供清除本游戏存档的按钮。清除操作只影响本游戏的存档。

## 验收标准

第一版通过以下条件才算完成：

1. 从小游戏中心可以看到本游戏卡片、版本号和“稳定版”标识。
2. 点击卡片可以打开 `three-kingdoms.html`，直接开始游戏。
3. 键盘和移动端均可以完成移动、对话、宝箱、地点切换和战斗操作。
4. 玩家可以完成一次普通战斗、一次武将加入事件和一次首领战。
5. 战斗结果、升级、军粮恢复和存档重新加载可重复验证。
6. 断开网络后，已加载的游戏不依赖外部图片、字体、脚本或音频才能运行。
7. 所有新增素材都有项目内来源记录，或由代码原创生成。
8. 现有坦克大战入口、二维码入口、版本显示和回归测试保持正常。

## 不包含在第一版的内容

第一版不包含完整原作章节、原作地图、原作剧情脚本、原作人物立绘、原作音乐、多人联机、排行榜、复杂装备系统、完整武将图鉴和大规模敌方 AI。完成垂直切片后，再根据试玩反馈决定下一阶段内容。
