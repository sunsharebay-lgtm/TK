# 吞食天地Ⅱ同人复刻 — 网页版

基于原作 TNW 引擎数据（RPG Maker MZ 格式 JSON）自研的纯浏览器运行时，无需任何原程序文件即可游玩。

## 启动方式

需要通过本地 HTTP 服务访问（浏览器安全策略禁止 file:// 下 fetch 资源）：

```bash
cd 吞食天地Ⅱ同人复刻-网页版
python3 -m http.server 8642
# 浏览器打开 http://localhost:8642
```

或使用启动脚本（自动起服务并打开浏览器）：

```bash
./启动游戏.sh
```

## 操作

| 按键 | 功能 |
|------|------|
| 方向键 / WASD | 移动、光标 |
| Enter / Space / Z / J | 确认、对话 |
| Esc / X / K | 取消、呼出菜单 |
| Shift | 加速移动 |
| U / I | 切换当前武将 |
| Q / E | 商店出售 / 购买 |

主菜单最后一项“返回标题”可回到标题画面；返回标题不会自动保存当前进度，需先在“存档”中保存。

物品栏中选择“地图”或“西蜀地图”后可查看世界地图，红色标记表示当前所在的大地图位置。
战斗中，使用我方单体恢复技能时按左键可改为我方全体，使用敌方单体伤害技能时按右键可改为敌方全体；全体恢复总量为单体的 1.25 倍，全体伤害总量为单体的 1.5 倍，最终仍受各武将剩余兵力上限影响。

战斗中的敌方普通攻击会以我方存活武将为目标，总攻和普通战斗都会正常还击；行动动画已放慢，便于看清攻击者、受击者和伤害。敌方策略会消耗谋略点，触发率和效果随智力变化；敌方无被动回复，普通回复按固定基础值加智力倍率，完复计直接补满。策略消耗按原始值约三分之二结算，武将谋略上限随等级额外成长。

武器和防具按可持有数量管理，重复装备可以分别给多个武将使用，卸下后会完整归还库存；装备预览使用两列布局，武力、速度等变化均可见。武将武力使用历史基准值，最终武力为基准加装备，物理攻击还会随当前兵力规模提升。

大地图空遭遇表会按队伍等级补充分层敌群，约 40 步触发一次遇敌。自由航行时只在海水图块上触发海贼敌群；剧情自动航行路线不会触发遇敌，船体会跟随队伍移动，剧情结束会自动停在合法陆地。

地图宝箱领取后会切换为打开状态，获得金钱会显示明确提示；第一章纪灵战后先前往大地图东北方挑战袁术，再进入寿春城和山洞。物品页显示道具、武器、防具，确认后可使用或丢弃 1 个；商店支持购买和出售，出售价格为买入价的 75%。袁术最终战胜利后会标记第一章完成并开放山洞出口，沿出口回到大地图、向西南返回徐州即可收尾；阶段 80 至 1655 的后续主线和二周目秦皇陵已接入运行时，章节路线见项目内全章节规划。客栈货币显示与收费分离，训练场会拒绝已经达到该训练场目标等级的队伍。

移动端浏览器会自动显示触屏方向键。郑家村村民位于湖西侧陆地；推进到书信剧情后进入郑玄居，可取得推荐袁绍的书信。新收武将按当前队伍平均等级加入，物品页的招魂丹可以选择阵亡武将复活。

非战斗单体恢复计策会先显示目标列表，确认目标后才扣除谋略点；scope 9/10 的复活技能只列阵亡武将。郑玄居兼容网页版跳过原作登录流程，拥有地图后与郑玄对话可取得书信。事件条件中的物品判断遵循 MV 的 `[类型, id]` 参数格式。

全章节按变量 1 的阶段推进：80-260 河北与千里走单骑，260-470 荆州新野与三顾茅庐，470-830 赤壁与荆州平定，830-1165 西蜀入川，1165-1440 汉中与姜维，1440-1605 灭曹魏，1605-1655 伐吴终局，1655 以后进入二周目秦皇陵。原始地图事件、战斗、招募和关键道具由同一运行时驱动。

## 调试参数（URL query）

- `?autostart` — 跳过标题直接开始新游戏
- `?autointro=N` — 每 N 帧自动按一次确认（自动推进开场剧情）
- `?goto=mapId,x,y` — 直接传送到指定地图坐标（配合 autostart）
- `?debug=1` — 打开章节试玩中心，选择完整试玩节点
- `?debug=1&preview=ch5-start` — 直接进入指定章节节点
- `?debug=1&preview=live` — 恢复上次按 `F6` 保存的现场

示例：`http://localhost:8642/?autostart&goto=159,14,7`

章节试玩中心按 `↑↓` 选择、`←→` 翻页、`Enter` 进入、`Esc` 返回标题。进入调试节点后，
按 `F6` 可保存当前地图、剧情阶段、队伍、兵力、谋略、物品、装备和遇敌步数；按 `F8`
可回到节点列表。调试模式使用独立存档前缀，不会覆盖正常游戏的四个存档记录。

## 目录结构

```
index.html          页面外壳（画布、触屏按钮）
js/
  core.js           输入、音频、图像、字体、缩放
  data.js           DataManager、游戏状态类（Party/Switches/Variables…）、存读档
  interp.js         事件解释器（MV 命令码）、Game_Map/Event/Player
  windows.js        窗口（消息/选择/金钱）、头像、转义符解析
  mapscene.js       图块渲染、角色精灵、Scene_Map
  menus.js          菜单/物品/技能/装备/状态/存读档/商店场景
  battle.js         战斗（侧视图）
  preview.js        开发用章节试玩中心与现场快照
  main.js           SceneManager、标题画面、主循环、启动流程
assets/
  data/             566 个解码后的 MZ 格式 JSON
  img/              图块/角色/头像/敌人等图片
  audio/            BGM/SE (ogg)
  fonts/            内嵌字体
tools/extract.py    从原版加密数据提取资源的脚本
```

## 技术说明

- 原版资源为 XOR 0x2F + 字节轮转加密，文件名为路径 MD5，已由 `tools/extract.py` 全量解码。
- 运行时为原创实现（非 MZ 内核），事件命令兼容 MV/MZ 编号（101 对话、102 选择、201 传送、205 移动路线等）。
- 主循环基于 `setTimeout` 16ms（约 60fps），输入边沿检测在帧末采样。
- 当前回归：浏览器 CDP 60/60，单元 327 项，冒烟 78 项；专项覆盖郑玄对话、恢复技能目标、招魂目标、章节试玩节点、恢复道具目标、渡船、返回标题、地图道具和群体技能目标。
