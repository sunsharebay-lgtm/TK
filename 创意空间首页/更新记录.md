## v0.1.0（初始）

- **日期**：2026-08-25
- **说明**：从「创意空间」根目录独立出来，作为独立项目。

### 本版内容

- `index.html`：游戏中心 / 起始页，品牌与标题为「创意空间」，通过卡片链接到各创意项目的游戏页面。
- `game-catalog.json` / `game-catalog.template.json`：游戏目录数据与生成模板。
- `scripts/generate-game-catalog.cjs`：读取 Git 稳定标签，按 `game/<game-id>/vX.Y.Z` namespace 生成 `game-catalog.json`。
- `测试/`：首页专属测试（`game_center_test.js`、`version_catalog_test.js`）。

### 说明

- 根目录 `index.html` 只是部署跳转页，不在此项目内；它自动跳到本项目的 `index.html`。
- 首页通过相对路径 `../坦克大战/...`、`../吞食天地三国/...` 链接各游戏。
