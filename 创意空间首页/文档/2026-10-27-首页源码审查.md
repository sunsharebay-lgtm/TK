## 已复现的页面问题

| 问题 | 复现证据 | 修复 |
| --- | --- | --- |
| 断网、HTTP 失败或 JSON 损坏一直显示“资源整理中” | 对实际首页脚本注入三种失败，均无法区分失败与空目录 | 独立加载/空目录/错误状态，显示重试与常驻“全部资料”入口 |
| 请求或响应体挂起无法结束加载 | 模拟不结束的响应，旧代码无超时，测试超时退出 | 请求及正文读取受同一个 8 秒取消信号控制，完成后清理计时器 |
| 坏条目导致整组列表失败 | `detailUrl: {}` 抛出 `.replace is not a function`；创意数组含 `null` 抛出读取 `url` 异常 | 按条校验必要字段、URL 范围、重复标识和编号，保留有效条目 |
| 创意数量先变化而卡片替换失败 | `[null]` 会先把数量写为 01，再在渲染处报错 | 构建并替换成功后更新数量，全坏目录保留静态入口并注明版本降级 |
| 标题不能作为资源入口 | 实际 DOM 的 `.resource-title` 下没有链接 | 标题与小号详情入口链接至同一资料，详情入口带唯一可读名称 |
| QQ 二维码仅有缩略图且被裁切 | 原图 1174×1050，页面固定 46×46 并 `object-fit: cover`，无大图入口 | 改为等比包含，缩略图链接至原图，键盘也可访问 |

## 展示优化

- 保留用户确认的一行式桌面资源列表。手机端将编号、日期、详情入口放在第一排，标题与简介在下方自然换行。
- 320、375、768、1024、1440 CSS 像素宽度下，检查页面右侧越界和资源标题/入口重叠，均为零。768px 及以上实际六条资料行高均为 48px。
- 页面标题、品牌返回标签、数量面板统一使用“创意中心/创意库”，与当前包含游戏、工具、资源库的定位一致。
- 移除首页已不使用的旧复制逻辑；资料页的复制功能仍由粉丝资源项目维护。

## 目录与验收脚本

- 目录生成复核发现：外部 `GIT_DIR` 等变量可覆盖仓库定位；缺少标题/网址仍能生成目录；带前导零的版本标签误当稳定版本。
- 发布验收复核发现：只检查脚本非空会放过损坏脚本；HTML 属性顺序/空白/注释影响引用识别；HTTP 跳转丢失最终相对路径基准；核心入口或脚本引用整体消失可漏检；测试子进程被杀会被误当作预期失败。
- 对应修复和最终测试结果见本项目 `project.md` 本日审查条目。
