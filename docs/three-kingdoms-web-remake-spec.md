# 吞食天地Ⅱ · 网页复刻 设计规格 v1

## 定位

以《吞食天地Ⅱ》（FC，1991）为机制基准的网页复刻，第一章"灭袁术"完整可玩。
机制与数值 1:1 复刻自参考数据；美术全部为程序绘制的原创 FC 风像素画；
剧情文字按公版《三国演义》脉络重写，不复制任何受版权保护的原文文本。

## 数据来源（已验证）

从参考版解密数据（RPG Maker MV 格式，XOR 0x2F）提取并生成内嵌表 `TK.*`：

- CLASSES 59 条：字 + 8 项成长曲线关键帧(lv1/15/30/60/99) + 计策习得表
- SKILLS 145 条：攻击/防御/逃跑 + 火水土三系伤害计策(系数320~4860, ×mat÷256)
  + 恢复系赤心→天仙计 + 辅助计策
- ITEMS：赤心丹系/智复丹系/招魂丹/会心丹/护身烟/解毒草等
- WEAPONS 273 / ARMORS 146：短剑10攻 → 青釭剑★★★270攻，价格原样
- ENEMIES 402：params=[mhp,mmp,atk,def,mat,mdf,agi]，exp/gold/AI行动表/掉落
- TROOPS 256：敌群编成（车胄=兵士×4、袁术总攻=袁术纪灵雷薄乐就杨弘…）

## 战斗公式（忠实）

- 物理伤害 = max(1, round((atk×4 − def×2) × U(0.8,1.2)))，会心率 luk 相关
- 我方计策 = coef × mat ÷ 256；敌方计策 = coef × mmp ÷ 960
- 恢复计策 = coef × mat ÷ 256（对己方）
- 行动顺序按 agi 排序；敌方 AI 按 rating 加权 + HP 阈值条件
  （如袁术 hp<50% 放赤心计回血、mp<20% 用智复计）
- 胜利得 exp/gold，掉落判定 1/denominator；升级按习得表学新计策

## 渲染方案

1920×1080 画布。地图图块逻辑 16px、整数放大 4 倍 → 64px，视口 30×15 格
（1920×960），底部 120px HUD 显示队伍兵力/金/地名。所有贴图为程序生成：
16×16 字符画调色板定义 → 离屏 canvas 光栅化 → drawImage 整数缩放，
image-rendering: pixelated 保证锐利。窗口 UI 为 FC 式白双线黑底。

## 状态机

title → world ⇄ menu(状态/道具/装备/存档) / dialogue / shop / inn /
battle → victory(levelup)/defeat(gameover)/retreat → chapter-end

按键：方向/WASD 移动，H 确认 J 取消 K 菜单 L 状态（1-5 快捷战斗指令兼容）。

## 第一章流程（灭袁术）

1. 徐州城开局：曹操令讨袁，朱灵/路昭加入（宫殿）
2. 城中收关羽/张飞，500金起步购物（武器店/道具店/役店/住宿）
3. 东门出城走大地图：黄巾/山贼随机战，徐州山洞宝箱支线
4. 纪灵拦路战（troop16），寿春城外高升孙仲（troop20）
5. 寿春城内两连战：袁术本阵（troop17）→ 总攻（troop19）
6. 章末结算：袁术败亡，经验军资总结，预告第二章
