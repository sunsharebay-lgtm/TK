# Mac 软件资源库

> 2026-10-28 起统一在创意空间管理。本地仅保留当前源码；下文历史归档路径指 GitHub 中的版本，不要求在本地恢复，也不再新增源码备份。最新规则见 [根 AGENTS.md](../AGENTS.md)。

创意空间的独立平级项目：按用途整理 Mac 软件，提供官方入口、Homebrew 命令与对应的夸克资料文件。首页以与坦克大战等项目相同的创意卡片级别展示，入口为 `../Mac软件资源库/`。

## 当前内容

- 数据源：`software-resources.json`；当前快照为 2026-09-09，收录 71 个软件、11 个用途分类。
- 页面入口：`index.html`，支持按名称、用途、来源、版本搜索，以及分类/交付类型筛选、打开夸克与复制链接。
- 测试：`测试/software_resources_test.js`，校验软件数据、永久分享、SHA-256、交付统计和页面功能。
- 历史归档：`历史版本/`；本项目自 2026-09-10 从粉丝资源升格为独立项目，后续被替换的页面与数据版本都归档在这里。

## 维护与授权边界

- 每个软件在夸克网盘 `项目/软件资源/` 下对应一个独立文件，并按用途放入分类子目录。
- 对公开源码或稳定官方发布物，且授权边界适合镜像的条目，提供实际安装包镜像。
- 对 App Store、商业闭源、授权不明确、需要登录或付费、原库缺少可确认来源的条目，提供 UTF-8 官方链接文本文件。
- 不上传破解软件、注册机、激活绕过工具、修改安装包或来源不明的安装包。
- 批处理先读取断点状态；每批 10～20 个，下载并发不超过 3、上传并发不超过 2；已完成项不得重复下载、上传或创建分享。

## 发版

稳定版本使用 `resource/mac-software-library/vX.Y.Z` 标签记录；GitHub Pages 只由 `main` 分支部署。提交后由创意空间统一执行线上验收，不能只依据标签或本地提交宣称已部署。

## 免责说明

软件来自互联网公开搜集与公开发布渠道，仅用于资料整理。下载和使用前请自行阅读软件官方许可、隐私政策与系统安全提示，并遵守软件作者和发行平台的授权要求；相关使用责任由使用者自行承担。

## 复制交互回归

修改复制逻辑时同时运行 `node 测试/clipboard_test.js`。该测试覆盖现代剪贴板、权限拒绝后的兼容复制，以及兼容接口返回 false 或抛错；只有确认成功才显示“已复制”。2026-10-26 审查修复记录与源文件校验见 `project.md`。
