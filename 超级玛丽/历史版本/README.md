# 历史版本归档

`超级玛丽` 项目确认版本的旧源码归档在这个目录；改名前的历史文件可能保留「超级像素兄弟」旧名称。

## 命名规则

- 成品文件：`index.html`（由 `src/` + `build.sh` 生成）
- 归档文件：`超级玛丽-vX.Y.Z.html`（版本号与 `更新记录.md` 中的条目一致）

## 归档时机

- 只有经过用户确认的版本才算新版本。
- 确认新版本时：把即将被替换的上一版 `index.html` 复制归档到这里，再在 `更新记录.md` 末尾追加记录。

## 开发前快照

- `2026-10-26-review-before/`：前一轮维护修复前的相关源码。
- `2026-10-27-playability-before/`：恢复可玩性开发前的完整 `src/`、`test/`、`build.sh`、`index.html` 和项目文档，包含当时尚未提交的维护修复。是可恢复快照，不代表另行发布。
