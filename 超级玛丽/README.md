# SUPER MARIO · 超级玛丽

一个致敬经典 FC 横版跳跃平台游戏的网页作品。玩法机制延续经典手感,
但**所有美术、音乐、关卡均为原创设计**(程序化绘制 + WebAudio 合成,零外部资源)。

> 当前状态：**待开发（暂停推进）**。现有 `v0.1.0` 仅作为可运行存档，后续可能重新设计。

## 运行方式

直接双击打开 `index.html` 即可游玩(无需服务器、无需联网)。

也可以在本地起个静态服务:

```bash
cd /Users/sun/Desktop/AI/创意空间/超级玛丽
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 操作

| 动作 | 按键 |
|------|------|
| 移动 | ← → 或 A D |
| 跳跃(长按跳更高) | K / 空格 / ↑ |
| 冲刺 & 发射火球 | L / Shift |
| 下蹲 / 进入水管 | ↓ / S |
| 暂停 | P / Esc |
| 音效开关 | M |

支持手柄与触屏(移动端自动显示虚拟按键),点击右上角 ⛶ 可全屏。

## 游戏内容

- **4 大关卡**:绿野平原 → 地底回廊 → 黄昏崖径 → 熔岩城堡
- **变身系统**:蘑菇变大 → 火焰花发射火球 → 无敌星短暂无敌
- **经典机制**:踩敌人、踢龟壳连击、顶砖块、多金币砖、隐藏 1UP 砖、
  奖励房传送水管、检查点、旗杆计分(越高分越多)、时间奖励与烟花
- **敌人**:栗子怪 ×N、龟壳兽(绿/红)、翼龟、食人花、旋转火棒
- 计分 / 金币(100 枚奖命)/ 生命 / 关卡解锁进度与最高分本地存档

## 工程结构

```
index.html          双击即玩的成品(构建产物)
src/
  00_head.html      页面外壳与样式
  10_core.js        常量 / 工具 / 输入(键盘+触屏+手柄)
  20_audio.js       WebAudio 音效合成 + 原创 chiptune 音乐序列器
  30_sprites.js     程序化绘制全部角色 / 方块 / 背景
  40_levels.js      关卡数据与构建器
  50_entities.js    敌人 / 道具 / 粒子实体
  60_player.js      玩家状态机与物理
  70_game.js        游戏状态机 / 相机 / 碰撞调度
  75_render.js      渲染管线 / HUD / 各界面
  90_main.js        主循环
build.sh            连接 src -> index.html 并做语法检查
test/harness.js     无头自动化测试(98 项断言)
```
