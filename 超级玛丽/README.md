# SUPER MARIO · 超级玛丽

一个致敬经典 FC 横版跳跃平台游戏的网页作品。玩法机制延续经典手感,
但**所有美术、音乐、关卡均为原创设计**(程序化绘制 + WebAudio 合成,零外部资源)。

> 当前版本：**v0.2.0（2026-10-27）**。四关玩法、操作与界面已改进，用户已确认发布；版本标签为 `game/super-mario/v0.2.0`，网页由 `main` 部署。旧版完整归档，验收记录见 `project.md` 与 `更新记录.md`。

## 这次可以玩什么

- **轻松探索**（默认）：不限生命、不限时，失误后从检查点快速继续。
- **经典挑战**：5 条生命，真实秒数倒计时；100 金币奖励生命，手动重试也消耗一条生命。
- 每关 **3 枚星币**：基础路线通关即可解锁下一关，高处支线用于收集挑战。星币在本局死亡后保留，完成该关后保存到收藏。
- 菜单支持鼠标、触屏、键盘和手柄。暂停可继续、重试或返回菜单；切到其他窗口会自动暂停。
- 初始关卡有移动、顶砖、跨坑与秘密水管提示；后续逐步引入移动平台、连续跳跃、熔岩与旋转火棒。

移动、刹车和转向更快；7 帧离地宽容、8 帧跳跃缓冲、可变跳高让起跳更容易掌握。高处的平台建议轻点跳，长距离跨坑时冲刺并长按。

## 运行方式

直接双击打开 `index.html` 即可游玩(无需服务器、无需联网)。

也可以在本地起个静态服务:

```bash
cd /Users/sun/Desktop/AI/创意空间/超级玛丽
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 操作

| 动作 | 按键 |
|------|------|
| 移动 | ← → 或 A D |
| 跳跃(长按跳更高) | K / Z / 空格 / ↑ |
| 冲刺 & 连续发射火球 | L / X / Shift |
| 下蹲 / 进入水管 | ↓ / S |
| 暂停 | P / Esc |
| 音效开关 | M |

支持手柄与触屏（移动端自动显示虚拟按键）；手机推荐横屏。右上角提供暂停、声音和全屏。手柄 A 跳跃/确认，B 或 X 冲刺，Start 暂停；菜单用方向键导航。死亡后可按跳跃键提前重试。

## 游戏内容

- **4 大关卡**:绿野平原 → 地底回廊 → 黄昏崖径 → 熔岩城堡
- **变身系统**:蘑菇变大 → 火焰花发射火球 → 无敌星短暂无敌
- **经典机制**:踩敌人、踢龟壳连击、顶砖块、多金币砖、隐藏 1UP 砖、
  奖励房传送水管、检查点、旗杆计分(越高分越多)、时间奖励与烟花
- **敌人**:栗子怪、绿壳龟、翼龟、食人花、旋转火棒
- 计分 / 金币(100 枚奖命)/ 生命 / 关卡解锁进度与最高分本地存档

## 测试

```bash
node test/harness.js
node test/input_test.js
node test/build_test.js
node test/gameplay_test.js
node test/playthrough_test.js
```

覆盖:物理手感与碰撞不变量模糊测试、方块交互、敌人 AI、道具效果、旗杆通关全流程、
传送水管往返、检查点重生、超时判负、随机压力测试(7500+ 帧)、
基础碰撞与渲染、性能冒烟等。`harness.js` 中的旧地形机器人仍只是有限探测；完整通关门禁以 `playthrough_test.js` 为准：3 个固定种子 × 4 关均断言真实进入结算，额外验证从第一关连续推进到最终胜利，不移除敌人、不传送、不添加生命或无敌。

```bash
node test/browser_test.cjs /absolute/path/to/node_modules/playwright
# 可选 CHROME_PATH 指定 Chrome；省略参数则使用可解析的 playwright 包。
```

## 开发与恢复

1. 先读 `AGENTS.md`、本手册、`project.md`、`更新记录.md`，保留工作区已有修改。
2. 只编辑 `src/`，运行 `bash build.sh` 生成 `index.html`；构建在语法检查成功后原子替换成品。
3. 运行以上五个 Node 测试；界面/交互变化还要跑浏览器检查并查看截图。
4. 记录交付、QA 与 SHA-256，旧源码归档。本地版本经确认后再由创意空间协调标签、首页目录和 `main` 部署。

依赖：Node.js（本轮使用 v24.20.0）、Bash。直接游玩只需支持 Canvas 2D 的现代浏览器；音频、全屏、存储失败时应能继续玩。

存档：旧 `spl_hi` / `spl_unlock` 兼容保留；`spl_save_v2` 保存模式、通关记录、星币位掩码。存档不包含关卡中的即时位置。`file://` 和本地 HTTP/线上地址的浏览器存储各自独立。

恢复本轮修改前版本：`历史版本/2026-10-27-playability-before/` 含 `src/`、`test/`、构建、成品与原文档；按需要比较和恢复，勿直接覆盖其他进行中的改动。历史索引见 `更新记录.md`。

## 经验与坑

- `ART.SS=4` 是素材分辨率，不是物理尺寸；瓦片绘制必须显式指定 16×16，避免画面与碰撞边界不一致。
- 敌人撞墙须保留原速度用于反弹；击杀加分统一走 `addScore`，连踩奖励生命不能把字符串加进数字分数。
- 奖励房必须有可落地的入口并缓存区域实体；不能返回主世界就重新生成已拿物品。
- 过关动画停止伤害与倒计时，跨关保留形态；暂停、死亡、成长冻结和传送需分别验证。
- 无头 Canvas 存根不能证明画面正确；浏览器截图与控制实测是独立验收项。
