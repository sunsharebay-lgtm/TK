## v0.1.0（初始）

- **日期**：2026-08-25
- **说明**：以「超级玛丽」名称作为独立创意纳入「创意空间」，但没有既定的正式版本标签，此条为归档起点。

### 本版内容

- **玩法**：致敬经典 FC 横版跳跃平台的网页作品。
  - 4 大关卡：绿野平原 → 地底回廊 → 黄昏崖径 → 熔岩城堡。
  - 变身系统：蘑菇变大、火焰花发射火球、无敌星短暂无敌。
  - 经典机制：踩敌人、踢龟壳连击、顶砖块、多金币砖、隐藏 1UP、奖励房传送水管、检查点、旗杆计分等。
  - 敌人：栗子怪、龟壳兽（绿/红）、翼龟、食人花、旋转火棒。
  - 计分 / 金币（100 枚奖命）/ 生命 / 关卡解锁与最高分本地存档。
- **工程**：`src/` 分片源码（核心/音频/精灵/关卡/实体/玩家/游戏/渲染/主循环）+ `build.sh` 构建。
- **测试**：`test/harness.js` 无头自动化，覆盖物理碰撞、方块交互、敌人 AI、道具、旗杆通关、传送水管、检查点、超时判负、随机压力与四关机器人通关等（98 项断言）。

### 运行方式

- 直接打开 `index.html` 即可游玩（无需联网）。
- 本地静态服务：`python3 -m http.server 8000`。
