# 粉丝资源

集中管理视频里提到的网址、模板、口令与可复制资料。

- 数据源：`resources.json`（每条含固定编号、日期、标题、简介、详情页地址）。当前资源至 `06`。
- 详情页：`资源/<资料名>/`，长资料独立维护。
- `06`「Mac 软件资源库」的 71 个软件数据单独维护在 `资源/Mac软件资源库/software-resources.json`，详情页提供搜索、分类筛选、交付类型筛选和夸克链接复制。
- 独立入口：`index.html`，按编号展示全部资源。
- 首页联动：创意空间首页读取 `../粉丝资源/resources.json` 展示最新几条，点击进入本站资料页。

## 维护流程

1. 新资源加入 `resources.json`，编号顺延（`02`、`03`...）。
2. 在 `资源/<资料名>/` 新增独立资料页。
3. 运行 `node 测试/resources_test.js` 校验数据与资料页。
4. 更新 `更新记录.md`；确认发布时打 `content/fan-resources/vX.Y.Z` 标签。

Mac 软件资源库的批处理约定：读取断点状态后按 10～20 个软件一批执行，下载并发不超过 3、上传并发不超过 2；完成项不得重复下载、上传或创建分享。公开发布物按授权边界决定是否镜像，其他条目只保存官方链接文本。

标签只是版本记录；不要在本项目对话中直接宣称已经部署。提交完成后通知创意空间，由创意空间推送 `main`，等待 Pages 线上验收通过。
