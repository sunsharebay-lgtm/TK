Package contents

WHAT THE ZIP ACTUALLY CONTAINS

核心结构

8 PROFILES
  • souls/：8 个 Hermes 运行人格。
  • skills/：7 份可复用的 Perspective Skill。
  • research/：每个角色的六维研究档案。
  • engine-source/：自包含的新版多顾问引擎。

安装与维护

READY TO RUN
  • README.md：安装包说明与使用建议。
  • METHOD.md：蒸馏方法、来源规则、质量门槛和更新流程。
  • manifest.json：版本与安全清单。
  • install.sh：创建 Profile、写入人格与技能、调整并发后端的安装器。

安装提示：先确认你自己的 Hermes 已安装并完成基础模型配置，再在包目录执行 bash install.sh。需要覆盖包内人格和 Skill 主文件时，再加 --force。
