# 粉丝资源 · 项目规则

- 本文件是「创意空间」的子项目「粉丝资源」的规则，直接受 `../AGENTS.md` 约束。
- 所有属于粉丝资源的当前源码、数据、资料页与测试都放在本文件夹内，不跨到兄弟项目。
- 上级：创意空间（`/Users/sun/Desktop/AI/创意空间`）；创意空间首页只读取展示，不负责维护内容。
- 发布：新增或修改资源后更新 `resources.json`、资料页、`更新记录.md`，并按 `content/fan-resources/vX.Y.Z` 打标签记录版本；由当前创意空间任务在用户明确说“推送”后推送 `main`，Pages 验收通过后才算发布。
- 数据约定：条目使用固定两位编号 `number`，每条必须提供 `detailUrl`；资料页放在 `资源/<资料名>/`。
- 工作方式：统一从创意空间项目接任务；先读根规则，再按本目录规则开发。涉及首页、资源数据或共享设施时，在同一任务内完成必要联动并分别验证，不再要求切换到独立子项目对话。
- 发布节奏：先完成本地修改和验证，等待用户明确说“推送”再执行统一发布；目录独立不要求单独注册 Codex 项目。
- 历史策略：本地只保留当前源码，不新增历史源码/中间版备份；旧 `历史版本/` 与退役实现按根 sparse checkout 规则排除，需要时从 GitHub 指定提交临时获取。旧文档的本地归档要求已失效。
