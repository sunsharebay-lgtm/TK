Install flow

THREE STEPS TO START

01 / Prepare

先安装 Hermes

确认接收者自己的设备已经安装 Hermes，并能运行 hermes --version 与 hermes profile list。

02 / Install

运行安装脚本

下载并解压安装包，在安装包目录执行 bash install.sh。脚本会创建或更新 8 个 Profile。

03 / Use

打开 Bots 面板

安装完成后打开 Hermes Desktop 的 Bots 面板；如果 Desktop 正在运行，请重启后读取新的并发设置。

Package notes

READ BEFORE RUNNING

安装包包含

8 BOTS
  • 7 位专业顾问：季琦、马斯克、张一鸣、罗振宇、巴菲特芒格、卡帕西、战略方法论老师。
  • 1 位中性主持人：智囊团主持人，负责选择专家、组织审议并综合结论。
  • 角色源文件、运行时人格文件、清单和安装脚本均已放在压缩包内。

安全边界

LOCAL ONLY
  • 安装包不包含 API Key、会话、记忆、state.db 或原拥有者的个人配置。
  • 脚本从接收者当前默认 Profile 克隆模型、凭据池和基础技能，不上传凭据。
  • 不会启动 Gateway，也不会创建外部消息平台连接；请只在自己的设备上运行。

覆盖提醒：如果某个 Profile 已经存在，默认只更新显示名和描述，不覆盖已有的 SOUL.md。确认要使用安装包版本覆盖时，再执行 bash install.sh --force。
