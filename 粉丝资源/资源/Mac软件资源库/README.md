# Mac 软件资源库

这是粉丝资源 `06` 号详情页对应的 Mac 软件目录。数据由同目录的 `software-resources.json` 驱动，页面入口为 `index.html`。

- 来源页面：飞书《【Mac】Mac软件库》
- 知识库：Mac张的分享中心
- 数据表：小张的Mac软件库
- 视图：软件汇总
- 盘点快照：2026-09-09
- 本次去重后共 71 个软件，按 11 个用途分类整理。

## 交付规则

- 每个软件在夸克网盘 `项目/软件资源/` 下对应一个独立文件，并按用途放入分类子目录。
- 对公开源码或稳定官方发布物，且授权边界适合镜像的条目，提供实际安装包镜像。
- 对 App Store、商业闭源、授权不明确、需要登录或付费、原库缺少可确认来源的条目，提供 UTF-8 官方链接文本文件。
- 不上传破解软件、注册机、激活绕过工具、修改安装包或来源不明的安装包。
- 每个条目都记录夸克文件路径、FID、永久分享链接和 SHA-256，页面提供打开夸克与一键复制功能。

## 页面功能

- 按软件名、用途、来源、版本搜索。
- 按用途分类和交付类型筛选。
- 查看版本、架构、来源、官方地址、GitHub/App Store 入口与 Homebrew 命令。
- 打开对应的夸克分享链接，或一键复制链接。
- 统计软件总数、分类数、安装包镜像数和官方链接文件数。
- 手机端单列布局，支持窄屏浏览。
