资源 07 / DeepSeek Harness

DSH 插件迁移包

把这套插件迁移到另一台装了 DeepSeek Harness 桌面端的机器上。你只需要下载、解压，再告诉目标机器上的 Agent 一句话：读一下 AGENT.md，按里面的要求做。

使用方法 / QUICK START

不需要记任何命令

STEP 01

拖到目标机器并解压

下载「dsh-plugin-kit.tar.gz」，拖到目标机器任意位置并解压，得到 dsh-plugin-kit 文件夹。

STEP 02

把一句话交给 Agent

让目标机器上的 Agent 能访问解压后的文件夹，再把下方的使用指令发给它。

STEP 03

按提示重启 DSH

Agent 会按包内说明走完 6 步，最后提示你完全退出并重新打开 DSH。你不需要记任何命令。

发给 Agent / COPY AND GO

复制这一句话

AGENT PROMPT

使用指令

在目标机器解压完成后，将这句话发给能够访问该文件夹的 Agent。

读一下 AGENT.md，按里面的要求做。

Agent 会做什么 / SIX STEPS

执行说明在 AGENT.md 中

  1. 核对目标机器的 DSH 版本、安装环境与插件清单。
  2. 先预演安装计划，检查将执行的操作。
  3. 备份目标配置并安装清单里的插件。
  4. 核对安装结果与插件加载列表。
  5. 按需要询问界面偏好与模型配置。
  6. 提示完全退出并重启 DSH，再检查插件是否生效。
使用前提：目标机器已安装 DeepSeek Harness 桌面端。包内清单以 DSH 0.2.1-rc.3 为参考环境，包含 16 个第三方插件的名称和版本，以及可选配置模板。插件依赖仍需联网下载；版本差异与可选配置按 Agent 提示确认，模型密钥由使用者自行配置。
